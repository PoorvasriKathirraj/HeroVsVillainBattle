HeroVsVillainBattle

This project implements a battle simulation between heroes and villains using Java. 
The program determines the minimum number of villains that must be removed from the front so that the heroes can defeat the remaining villains.
Each hero has the same health and fights villains sequentially in the given order.
During each battle, the health of the hero and villain is updated based on the fight rules.
The simulation continues until all villains are defeated or the heroes run out.
The solution focuses on efficient battle simulation and logical decision making.
